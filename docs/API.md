# API Reference

The ARE backend is built with **FastAPI** (`api.py`) and provides REST endpoints alongside Server-Sent Events (SSE) for real-time frontend integration.

## Base URL
`http://localhost:8000`

---

## Endpoints

### 1. Start Research Session
`POST /api/research`

Initializes a new LangGraph state machine flow.

**Request Body**:
```json
{
  "question": "Your research topic here"
}
```

**Response**:
```json
{
  "session_id": "a1b2c3d4",
  "status": "started"
}
```

---

### 2. Stream Events (SSE)
`GET /api/events/{session_id}`

Provides real-time Server-Sent Events showing the step-by-step reasoning and phase transitions of the ARE backend.

**Event Types**:
- `start`: Research initiated.
- `node_reasoning`: Agent internal thought process.
- `node_complete`: A graph node has finished processing.
- `hitl_required`: The workflow is paused, waiting for human input.
- `error`: Execution failed.
- `complete`: Research process finished entirely.

---

### 3. Check Status
`GET /api/status/{session_id}`

Polling endpoint for the current state of a graph run.

**Response**:
```json
{
  "status": "running|completed|error",
  "current_node": "node_4",
  "hitl_pending": true,
  "hitl_payload": {...},
  "verdict": null
}
```

---

### 4. Provide Human Input (HITL)
`POST /api/approve/{session_id}`

Allows the user to resume the graph when it is paused at `NODE-0 Confirm`, `NODE-4`, or `NODE-7`.

**Request Body**:
```json
{
  "action": "approve", // Or "reject" / "refine"
  "feedback": "Optional notes from user"
}
```

---

### 5. Fetch Final Report
`GET /api/report/{session_id}`

Retrieves the generated Markdown and JSON reports once the session status is `completed`.

---

### 6. Get Experiment Code 
`GET /api/experiment-code/{session_id}`

Retrieves code generated by `NODE-5` for the user to execute locally constraints require manual operation.

---

### 7. Submit Experiment Results
`POST /api/submit-results/{session_id}`

Submits locally executed results back into the system so `NODE-6` (Critic) can analyze them.

**Request Body**:
```json
{
  "results": {
    "metrics": {...}
  },
  "notes": "Optional observations."
}
```
